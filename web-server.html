Web servers - Internet Terminology

Web Servers

A web server is a computer that stores, processes, and delivers web pages to users over the internet. When a browser requests a webpage, the web server processes the request and sends back the appropriate files using HTTP. Popular web server software includes Apache, Nginx, and Microsoft IIS.
